# OPTIMATECH Design System v5

Sistema de design oficial da OPTIMATECH — identidade visual, tokens de cor, tipografia, componentes UI e guias de voz & tom.

## Páginas

| Arquivo | Conteúdo |
|---------|----------|
| `index.html` | Visão geral do sistema |
| `marca.html` | Logo, uso e variações |
| `cores.html` | Paleta e tokens de cor |
| `tipografia.html` | Fontes e escala tipográfica |
| `componentes.html` | Biblioteca de componentes UI |
| `voz.html` | Voz, tom e linguagem da marca |
| `assets.html` | Biblioteca de assets e ícones |

## Deploy

Hospedado em: https://optimatech-design-system.netlify.app

## Uso

Abra qualquer arquivo `.html` diretamente no browser — sem dependências externas.
